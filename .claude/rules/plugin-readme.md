# Plugin README Updates

When adding or modifying skills, hooks, agents, or other plugin components, always update the plugin's own `README.md` (e.g., `plugins/<name>/README.md`) to reflect the changes.

Ensure the README documents:
- **New skills/hooks/agents** — add a section with description, key behaviors, and triggers
- **Changed behavior** — update the relevant section to match the new behavior
- **New dependencies** — add entries to the Requirements table
- **Removed components** — remove the corresponding section
